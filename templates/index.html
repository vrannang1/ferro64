Your assistant

Give it a standing job, like researching your stocks every weekday morning. It searches the web, reads the pages that matter, checks prices, and leaves you a report with its sources. It can only read: it has no access to a brokerage, so it cannot buy or sell anything. It suggests; you decide.

Reports on your phone

Telegram · off

Ferro64 sends each finished report (and its CSV) to your own Telegram chat. Only Ferro64 sends, only to the chat you pick here; the assistant has no way to message anyone. 1. In Telegram, message @BotFather, send /newbot and copy the token it gives. 2. Paste it here and save. 3. Send your new bot "hi", then press find my chat.

Reports by email

Email · off

Ferro64 emails each finished report, with its sources and any CSV attached, from your own mail account. It sends only to the addresses you list here; the assistant cannot send email itself. Use an app password, not your normal password.

Code with a local model

Add a project folder. The agent reads it freely, but every edit and command waits for your approval, and a run can be undone. It is here to help you fix errors, write functions and do small tasks. For big tasks, use a bigger model, API keys or other tools. Read and run what it gives you.

API models

Use a vendor's models with the coding agent. These are not local: while one is selected, your project's code goes to that vendor. They also get expensive, because every step resends the whole conversation and you pay per token, so a local model or a flat subscription is the better everyday choice. Keep these for when you are truly stuck. Keys are kept on this machine, in Ferro64's database, and are never shown again.
